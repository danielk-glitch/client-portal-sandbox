# Shared brand assets

These are the supplied PLACE and Brivity SVGs, renamed for predictable imports. Import them through `src/assets/brand/index.ts` so the portal, email previews, and future surfaces use the same files.

The logo choice is a product decision, not a color token. The current email review previews use the team and brokerage logos from the seller portal's sample transaction. Brivity variants are available here for flows that require that identity.
